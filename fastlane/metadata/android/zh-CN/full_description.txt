Median Browser 是一款轻量 Android 浏览器，使用设备自带的 Android System WebView 渲染网页，因此应用本身只有约 300 KB，不必再内置一个 Chromium 内核。

日常浏览需要的能力都在里面，数据默认只留在你的设备上。

广告过滤
• 支持 ABP / hosts 规则、过滤订阅、逐站点开关与页面元素隐藏
• 点选网页上的广告元素即可隐藏，保存前会校验选择器
• 规则更新立即生效，无需重启

本地密码库
• 基于 Android Keystore 与 AES-GCM 加密
• HTTPS 页面自动填充、保存提示、加密便携备份
• 退到后台立即重新锁定

用户脚本
• 类 Tampermonkey 的用户脚本，兼容常用 GM / GM4 API
• document-start 注入、按网站匹配、网络请求 @connect 校验
• 可从 Greasy Fork、链接或粘贴代码安装

下载与离线阅读
• 支持暂停、继续、分段下载与重试
• 网页保存为本地离线页面；阅读模式、系统朗读、网页翻译、页内查找
• 可选择下载目录，或把链接交给外部下载应用

隐私
• 独立隐私窗口，会话与普通浏览隔离，退出即清理
• 不包含广告、分析或崩溃上报 SDK
• 没有开发者账号、同步服务器或遥测后台
• 逐站点权限，可按需检查 TLS 证书

按自己的习惯使用
• 自定义主页：背景、布局、搜索引擎、常用网站
• 标签管理、主题切换、边缘滑动导航、二维码扫描、媒体探测

Median Browser 以 GPL-3.0 协议开源，源码与问题反馈：https://github.com/bi-box/Median

需要 Android 8.0（API 26）及以上；隐私窗口需要 Android 9.0（API 28）。网页兼容性取决于设备上的 Android System WebView，建议保持更新。
