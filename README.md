# 📦 编译项目

## 环境要求

需要：

- Android Studio
- JDK 17+
- Android SDK


## 克隆项目

```bash
git clone https://github.com/bi-box/Median.git
```

进入目录：

```bash
cd Median
```

## 编译 Release

```bash
./gradlew assembleRelease
```

生成 APK：

```
app/build/outputs/apk/
```
